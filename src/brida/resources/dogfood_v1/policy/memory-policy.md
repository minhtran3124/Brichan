# Project memory policy

Read progressively:

1. Read `.brida/project-memory/index.md`.
2. Read a project's `overview.md` and `current-state.md`.
3. Read `tasks.md` when planning or coordinating work.
4. Read `decisions.md` only when a past trade-off affects the request.
5. Read `references.md` only when evidence or external context is needed.

Store stable facts in `overview.md`, current status and next actions in
`current-state.md`, decisions and rationale in `decisions.md`, active ownership
in `tasks.md`, and source or evidence pointers in `references.md`. Record
verified facts rather than raw chat history, and label unverified claims.
